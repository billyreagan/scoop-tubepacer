# Scoop bucket for tubepacer

[tubepacer](https://github.com/billyreagan/tubepacer) downloads YouTube on Windows and paces itself to stay under YouTube's limits. Built on yt-dlp.

```
scoop bucket add tubepacer https://github.com/billyreagan/scoop-tubepacer
scoop install tubepacer
```

This installs the `ytdl` command, plus yt-dlp, ffmpeg and deno from Scoop's main bucket. Run `ytdl -Doctor` to check the setup.
